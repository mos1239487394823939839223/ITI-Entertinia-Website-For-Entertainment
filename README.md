# Entertainment Website

## Overview
The Entertainment Website is a dynamic web application built using HTML, CSS, JavaScript, Bootstrap, and jQuery. This project serves as a platform for users to access the latest sports news, movie ratings, and direct links to new movies. Additionally, it features engaging games created using HTML, CSS, and pure JavaScript.

## Features
- **Sports News**: Stay updated with the latest news and articles related to various sports.
- **Movie Ratings**: View ratings and reviews for popular movies.
- **Direct Links to New Movies**: Access links to the latest movie releases for easy viewing.
- **Interactive Games**: Enjoy a selection of games built with HTML, CSS, and JavaScript, providing entertainment and fun.

## Technologies Used
- **Languages**: HTML, CSS, JavaScript
- **Frameworks/Libraries**: Bootstrap, jQuery
